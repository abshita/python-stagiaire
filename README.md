# Python Stagiaire

Ce dépôt est un parcours simple pour apprendre Python progressivement, de la base jusqu’aux mini projets.

## Objectif

Apprendre les fondamentaux de Python, comprendre les concepts principaux et créer des mini projets pour renforcer la pratique.

## Organisation du projet

- `basic/` : notions de base
- `avanced/` : sujets plus avancés
- `cryptographie/` : exemples de cryptographie
- `TP/` : travaux pratiques par niveau
- `Help.md` : aide-mémoire Python, Linux et pip

## Progression recommandée

### Niveau 1 : Variables et types
- chaînes, nombres, booléens
- affichage avec `print()`
- lecture avec `input()`

### Niveau 2 : Conditions
- `if`
- `elif`
- `else`

### Niveau 3 : Boucles
- `for`
- `while`

### Niveau 4 : Fonctions
- `def`
- `return`
- paramètres

### Niveau 5 : Mini projets
- gestion de notes
- mini calculatrice
- gestion de listes

### Niveau 6 : Sujets avancés
- listes avancées
- dictionnaires
- tuples
- modules
- classes

### Niveau 7 : Cryptographie
- hashage
- Base64
- César
- XOR

## Comment utiliser ce dépôt

1. Ouvre le dossier `basic/` pour commencer.
2. Exécute chaque fichier Python.
3. Modifie les valeurs et teste le comportement.
4. Passe ensuite dans `TP/` pour travailler par niveau.
5. Continue dans `avanced/` et `cryptographie/`.
6. Utilise `Help.md` comme aide-mémoire.

## Commande Git pour relier le dépôt distant

Si tu veux connecter ce projet à GitHub, utilise :

```bash
git remote set-url origin https://github.com/abshita/python-stagiaire.git
```

Ensuite :

```bash
git branch -M main
git push -u origin main
```

## Conseils pour monter en compétence

- Fais un exercice avant de passer au suivant.
- Réécris les exemples avec tes propres valeurs.
- Crée un mini projet personnel à la fin de chaque niveau.
- Ne passe pas trop vite : la pratique est plus importante que la théorie.
- Relis les messages d’erreur, ils te disent souvent la solution.

## Astuce

Pour progresser rapidement, essaie de refaire chaque fichier sans regarder le code, puis compare avec la solution.
